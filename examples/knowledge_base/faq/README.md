# FAQ 常见问题

本目录包含各类常见问题解答。

---

## 目录

| 文件 | 说明 |
|------|------|
| `account.md` | 账户管理相关问题 |
| `billing.md` | 计费与支付相关问题 |
| `technical.md` | 技术问题与API使用 |
| `general.md` | 通用问题（待补充） |

---

## 使用说明

当用户提问时，优先匹配 `troubleshooting/` 目录（如果提到错误/故障），
其次匹配本目录的 FAQ 内容。

---

## 添加新 FAQ

在对应分类文件中按以下格式添加：

```markdown
## Q: {问题标题}

**分类**: {account/billing/technical/general}
**优先级**: {P1/P2/P3}
**更新**: {日期}

### 问题描述
{详细描述}

### 解决方案
1. {步骤1}
2. {步骤2}
3. {步骤3}
```

---

## 审核流程

1. 客服团队提出新增/修改需求
2. 产品团队审核内容准确性
3. 更新到知识库并记录版本
