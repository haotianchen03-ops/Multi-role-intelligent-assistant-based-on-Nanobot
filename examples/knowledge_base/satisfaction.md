# 满意度评价功能

> 用于收集和追踪用户满意度

---

## 功能说明

在问题解决后，主动邀请用户评价服务质量。

---

## 评价触发条件

| 场景 | 触发时机 |
|------|---------|
| FAQ回答后 | 用户表示满意时 |
| 工单关闭后 | 系统自动发送评价邀请 |
| 对话结束时 | 主动邀请用户反馈 |

---

## 评价维度

| 维度 | 说明 | 分值 |
|------|------|------|
| **响应速度** | 等待时间是否合理 | 1-5 ⭐ |
| **回答质量** | 是否解决了问题 | 1-5 ⭐ |
| **沟通体验** | 对话是否流畅友好 | 1-5 ⭐ |
| **整体满意度** | 综合评分 | 1-5 ⭐ |

---

## 评价收集流程

### 1. 触发评价

```
您好，您的问题已解决了吗？
如果方便，请对我的服务进行评价：

1️⃣ 响应速度：⭐⭐⭐⭐⭐
2️⃣ 回答质量：⭐⭐⭐⭐⭐
3️⃣ 沟通体验：⭐⭐⭐⭐⭐
4️⃣ 整体满意：⭐⭐⭐⭐⭐

直接回复数字即可，如：1-5,2-5,3-4,4-5
```

### 2. 解析评价

支持多种格式：
- `1-5,2-5,3-5,4-5` - 标准格式
- `全部5星` - 自然语言
- `4.5` - 单项评分

### 3. 记录评价

```python
{
  "user_id": "U123456",
  "ticket_id": "T2026040001",
  "timestamp": "2026-04-28T00:30:00",
  "scores": {
    "speed": 5,
    "quality": 5,
    "experience": 4,
    "overall": 5
  },
  "comment": "响应很快，解答清晰",
  "suggestion": "希望增加更多FAQ"
}
```

---

## 评价数据分析

### 周报统计

| 指标 | 本周 | 上周 | 变化 |
|------|------|------|------|
| 评价数量 | 45 | 38 | +18% |
| 平均整体 | 4.6 | 4.4 | +5% |
| 平均质量 | 4.7 | 4.5 | +4% |
| 差评率(<3) | 2% | 5% | -60% |

### 低分预警

当评分 < 3 时：
1. 自动创建工单
2. 通知客服主管
3. 标记需要人工跟进
