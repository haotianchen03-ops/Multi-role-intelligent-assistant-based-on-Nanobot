# 产品概览

---

## 产品简介

我们的产品是一款**多平台智能客服系统**，帮助企业统一管理多渠道客户咨询，提升服务效率。

---

## 核心功能

| 功能 | 说明 |
|------|------|
| 🤖 智能问答 | 基于知识库的自动回复，覆盖80%常见问题 |
| 📋 工单管理 | 自动创建工单，交给人工客服处理 |
| 🌐 多平台支持 | 飞书、钉钉、Telegram、微信等 |
| 📊 数据分析 | 实时统计咨询量、响应时间、满意度 |
| 🔧 快速集成 | 提供 API 和 Webhook，灵活对接现有系统 |

---

## 技术架构

```
用户 → Channel(飞书/钉钉/TG) → MessageBus → Agent
                                              ↓
                                         Skills(FAQ/工单)
                                              ↓
                                         Knowledge Base
                                              ↓
                                         MCP Server
```

---

## 适用场景

- 🛒 电商咨询
- 💼 B2B 技术支持
- 🏥 医疗问诊
