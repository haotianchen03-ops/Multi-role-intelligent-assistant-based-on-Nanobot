# 多平台智能客服 Bot 测试指南

---

## 测试前准备

### 1. 启动 nanobot

```bash
nanobot run --config config.json
```

### 2. 检查 MCP Server 状态

确保 `ticket_server.py` 已启用（需在 config.json 中取消注释）

---

## 测试用例

### 测试1: FAQ 查询

**目的**: 验证知识库检索是否正常

**测试步骤**:
1. 发送消息: "API调用超时怎么办"
2. 检查回复是否来自 `knowledge_base/troubleshooting/`

**预期结果**: 回复包含超时解决方案

---

### 测试2: 工单创建

**目的**: 验证 MCP Server 是否正常工作

**测试步骤**:
1. 发送消息: "我要反馈一个问题"
2. 根据提示描述问题
3. 确认工单创建成功

**预期结果**: 返回工单号（如 #T2026040001）

---

### 测试3: 用户记忆

**目的**: 验证 MEMORY.md 是否正确更新

**测试步骤**:
1. 完成一次对话后
2. 检查 `D:\ai\.nanobot\workspace\MEMORY.md`

**预期结果**: 文件中包含你的用户记录

---

### 测试4: 满意度评价

**目的**: 验证评价收集功能

**测试步骤**:
1. 问题解决后发送 "满意" 或 "解决了"
2. 检查是否触发评价邀请

**预期结果**: 收到4维度评价请求

---

### 测试5: 多语言支持

**测试步骤**:
1. 发送英文: "I forgot my password"
2. 检查回复语言是否为英文

**预期结果**: 英文回复，提供密码重置指引

---

## 快速测试命令

```bash
# 测试飞书连接
nanobot test --channel feishu

# 测试钉钉连接
nanobot test --channel dingtalk

# 查看知识库状态
nanobot kb --list

# 查看工单列表
nanobot ticket --list
```

---

## 常见问题排查

| 问题 | 可能原因 | 解决方法 |
|------|---------|---------|
| 无法回复 | MCP Server 未启动 | 检查 config.json 并重启 |
| 知识库不匹配 | 搜索关键词不对 | 尝试不同的表述 |
| 工单创建失败 | 权限问题 | 检查 MCP 配置 |
